## ✅ ما طلبته وكيف تم تنفيذه

| الطلب | التنفيذ |
|---|---|
| يعمل 24 ساعة دون توقف | حلقة تشغيل مستمرة + إعادة محاولة تلقائية عند انقطاع الإنترنت/أخطاء المنصة + Docker `restart: always` أو systemd. يحفظ حالته ويكمل بعد إعادة التشغيل. |

| رافعة 20، و50 إذا كانت "مضمونة" | رافعة **20x** للصفقات العادية (تقييم ≥ 65)، و**50x** للصفقات A+ فقط (تقييم ≥ 85 + توافق كل الفريمات + حجم + تمويل). البوت يضبط الرافعة على العملة قبل كل صفقة. إذا كان الوقف أبعد من حد الأمان لـ50x ينزل تلقائياً إلى 20x، وإذا كان أبعد من حد 20x يرفض الصفقة. |
| الصفقات لونج أو شورت | يتداول بالاتجاهين حسب السوق (`direction: both`)، ويمكنك حصره بأمر: `لونج فقط` أو `شورت فقط`. |
| يفهم الأمر وينفذه | أوامر بالعربي والإنجليزي عبر تيليجرام (انظر قائمة الأوامر). |
| أقوى خبرات التداول | استراتيجية "التوافق متعدد الفريمات" تجمع أشهر أساليب المحترفين (انظر الأسفل). |

## 🧠 الاستراتيجية (كيف يقرر البوت)

يحسب البوت **تقييماً من 100** لكل اتجاه، ولا يدخل إلا عند توافق عدة مدارس تحليل:

1. **التحليل من الأعلى للأسفل (Top-Down):** اتجاه 4 ساعات (EMA50/EMA200) + اتجاه الساعة (EMA21/55 + Supertrend + ADX/DMI).
2. **تتبع الاتجاه على فريم 15 دقيقة:** ترتيب المتوسطات 9/21/55، Supertrend، زخم MACD متزايد، RSI في "منطقة القوة" 50–70 (وليس متشبعاً).
3. **محفز دخول إلزامي:** إما **ارتداد من EMA21** مع شمعة تأكيد، أو **اختراق قناة دونشيان (20)** مع حجم تداول مرتفع.
4. **التقلب:** انفجار بعد انضغاط بولنجر يزيد الثقة.
5. **تموضع السوق:** معدل التمويل (Funding) — يتجنب الجهة المزدحمة.
6. **عدم مطاردة السعر:** يرفض الدخول إذا ابتعد السعر أكثر من 2.5 ATR عن EMA21.
7. **وقف خسارة هيكلي:** تحت/فوق آخر قاع/قمة، محصور بين 1–2.5 ATR.
8. **إذا كان السوق متضارباً** (لونج وشورت كلاهما مرتفعان) لا يدخل.

### إدارة الصفقة
- **الهدف 1** = 1.5 ضعف المخاطرة → يغلق 50% وينقل الوقف لنقطة الدخول (صفقة بلا خسارة).
- **الهدف 2** = 3 أضعاف المخاطرة → يغلق الباقي.
- **وقف متحرك** (2 ATR) بعد الهدف الأول لحماية الأرباح.
- وقف الخسارة والهدف النهائي يُرسلان **مع الأمر إلى المنصة نفسها**، فالصفقة محمية حتى لو توقف البوت أو انقطع السيرفر.
- ⚠️ في الهامش المتبادل، وقف الخسارة في المنصة هو الحماية الأساسية: لو حدثت فجوة سعرية حادة قد تتجاوز الخسارة 2% لأن الرصيد كله ضامن للصفقة (في المعزول تتوقف الخسارة عند هامش الصفقة).

### حماية الحساب
- حد أقصى 3 صفقات مفتوحة.
- إيقاف الدخول لبقية اليوم عند خسارة 6% من الرصيد.
- استراحة ساعتين بعد 3 خسائر متتالية.
- انتظار 45 دقيقة قبل العودة لنفس العملة.
- إغلاق الصفقة إذا طالت أكثر من 36 ساعة.

كل هذه القيم قابلة للتعديل في `config.yaml`.

## 🚀 التشغيل

### 1) التجهيز
```bash
cd mexc_bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # ثم عدّل الملف
```

### 2) مفاتيح MEXC API
1. من موقع MEXC: **الملف الشخصي → إدارة API → إنشاء API**.
2. فعّل صلاحية **العقود (Futures / Contract) – تداول**. **لا تفعّل السحب أبداً.**
3. اربط المفتاح بعنوان IP السيرفر (موصى به جداً).
4. ضع المفتاح والسر في `.env`.

> ℹ️ MEXC تقيّد أحياناً تداول العقود عبر API لبعض الحسابات. إذا ظهر خطأ صلاحيات عند فتح أول صفقة حقيقية، تواصل مع دعم MEXC لتفعيل Futures API لحسابك.

### 3) تيليجرام (للتحكم والإشعارات)
1. افتح [@BotFather](https://t.me/BotFather) → `/newbot` → انسخ التوكن إلى `TELEGRAM_BOT_TOKEN`.
2. أرسل أي رسالة لبوتك، ثم افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وانسخ رقم `chat.id` إلى `TELEGRAM_CHAT_ID`.
3. البوت يقبل الأوامر **منك فقط** (من هذا الـ chat id).

### 4) الاختبار التاريخي (Backtest)
```bash
python backtest.py --symbol BTC/USDT:USDT --days 90
python backtest.py --symbol ETH/USDT:USDT --days 90
```

### 5) التشغيل التجريبي (أموال وهمية، أسعار حقيقية)
```bash
python -m bot        # BOT_MODE=paper في .env
```

### 6) التشغيل الحقيقي 24/7 على سيرفر (VPS)
غيّر `BOT_MODE=live` في `.env` ثم:

**Docker (الأسهل):**
```bash
docker compose up -d --build
docker compose logs -f
```

**أو systemd:**
```bash
sudo cp mexc-bot.service /etc/systemd/system/   # عدّل المسارات واسم المستخدم داخله
sudo systemctl enable --now mexc-bot
journalctl -u mexc-bot -f
```

> 💡 جهازك الشخصي ينطفئ وينقطع عنه الإنترنت؛ للعمل 24/7 فعلاً استخدم VPS (يكفي أصغر سيرفر بـ 1GB RAM).

## 💬 أوامر تيليجرام

| الأمر | الوظيفة |
|---|---|
| `الحالة` | حالة البوت، الرصيد، الصفقات المفتوحة وأرباحها |
| `الرصيد` | الرصيد وربح اليوم |
| `تحليل BTC` | تحليل كامل للعملة مع التقييم والأسباب |
| `لونج BTC` / `شراء BTC` | فتح لونج يدوي (بنفس قواعد 2% والوقف والأهداف) |
| `شورت ETH` / `بيع ETH` | فتح شورت يدوي |
| `اغلاق BTC` | إغلاق صفقة |
| `اغلاق الكل` | إغلاق كل الصفقات |
| `ايقاف` / `تشغيل` | إيقاف/استئناف فتح صفقات جديدة |
| `لونج فقط` / `شورت فقط` / `الاتجاهين` | تحديد اتجاه الصفقات |
| `الصفقات` | آخر الصفقات المغلقة |
| `مساعدة` | قائمة الأوامر |

الأوامر الإنجليزية تعمل أيضاً: `/status /balance /analyze BTC /long BTC /short ETH /close BTC /closeall /pause /resume /mode long|short|both /trades /help`.
