# 🧭 دليل المبتدئ: تشغيل البوت خطوة بخطوة (بدون أي خلفية تقنية)

## الفكرة باختصار
منصة MEXC **لا تشغّل البوت بنفسها**. البوت برنامج يعمل على **كمبيوتر** ويرسل الأوامر للمنصة عبر "مفاتيح API".
ولأنه يجب أن يعمل 24 ساعة، نستأجر **سيرفر صغير على الإنترنت (VPS)** يبقى شغالاً دائماً.

```
[ سيرفر VPS يعمل 24/7 ]  ──مفاتيح API──▶  [ حسابك في MEXC ]
            │
            └──▶ رسائل وأوامر على تيليجرام في جوالك
```

الوقت المطلوب: حوالي **ساعة** أول مرة.

---

## الخطوة 1: تجهيز حساب MEXC
1. سجّل في MEXC وأكمل **توثيق الهوية (KYC)**.
2. اشترِ أو حوّل **USDT** إلى حسابك.
3. **مهم:** انقل الـ USDT من محفظة **Spot** إلى محفظة **Futures (العقود)**:
   `الأصول (Assets) ← تحويل (Transfer) ← من Spot إلى Futures`.
   البوت يتداول فقط بالرصيد الموجود في محفظة العقود.
4. لا تفتح صفقات يدوية على نفس الحساب أثناء عمل البوت (أو استخدم **حساباً فرعياً Sub-account** للبوت فقط — أفضل وأأمن).

## الخطوة 2: إنشاء مفاتيح API في MEXC
1. من التطبيق أو الموقع: `الحساب ← إدارة API (API Management) ← إنشاء API`.
2. فعّل صلاحية **العقود Futures (التداول / Trade)**.
3. ❌ **لا تفعّل السحب (Withdraw) أبداً.** بهذا حتى لو سُرق المفتاح لا يستطيع أحد سحب أموالك.
4. احفظ **Access Key** و **Secret Key** في مكان آمن (الـ Secret يظهر مرة واحدة فقط).
5. لاحقاً بعد استئجار السيرفر: ارجع وعدّل المفتاح واربطه **بعنوان IP السيرفر** (حماية إضافية قوية).

## الخطوة 3 (اختياري لكن أنصح به): بوت تيليجرام للتحكم من جوالك
1. في تيليجرام ابحث عن **@BotFather** ← اكتب `/newbot` ← اختر اسماً ← سيعطيك **توكن** (رقم طويل). احفظه.
2. ابحث عن **@userinfobot** ← اضغط Start ← سيعطيك **Id** (رقمك). احفظه.
3. افتح البوت الذي أنشأته واضغط **Start** (حتى يستطيع مراسلتك).

## الخطوة 4: استئجار سيرفر VPS
أي شركة تعمل. الاختيار المناسب: **Ubuntu 24.04**، **1GB RAM** أو أكثر، الموقع **أوروبا (ألمانيا مثلاً) أو سنغافورة**.
- ❗ **لا تختر سيرفر في أمريكا** — MEXC تقيّد المستخدمين من الولايات المتحدة.
- خيارات معروفة: Hetzner، Contabo، DigitalOcean، Vultr (حوالي 4–6 دولار شهرياً).
- خيار مجاني: **Oracle Cloud – Always Free** (يحتاج بطاقة للتسجيل فقط).

بعد الشراء ستحصل على: **عنوان IP** و **كلمة مرور** (أو مفتاح) للمستخدم `root`.

## الخطوة 5: الدخول للسيرفر
- **من ويندوز:** افتح برنامج **PowerShell** واكتب:
  ```
  ssh root@عنوان_IP_السيرفر
  ```
- **من الآيفون/أندرويد:** حمّل تطبيق **Termius** وأضف السيرفر بالـ IP وكلمة المرور.
- **أو** من لوحة تحكم الشركة نفسها: زر **Console** يفتح لك شاشة السيرفر في المتصفح.

اكتب `yes` إذا سألك، ثم كلمة المرور (لن تظهر أثناء الكتابة — هذا طبيعي).

## الخطوة 6: تثبيت البوت (انسخ والصق فقط)
الصق هذه الأوامر واحداً تلو الآخر واضغط Enter بعد كل واحد:

```bash
apt-get update && apt-get install -y git
git clone -b claude/mexc-futures-trading-bot-w9nv87 https://github.com/binali13d/crypto.git
cd crypto/mexc_bot
./bot.sh install
```

الأداة ستسألك عن:
1. **API Key** ← الصقه.
2. **Secret Key** ← الصقه (لن يظهر أثناء اللصق، طبيعي).
3. **توكن تيليجرام** و **رقمك** ← الصقهما (أو Enter للتخطي).
4. **الرصيد الوهمي للتجربة** ← اكتب `100`.

بعدها البوت يبدأ **بالوضع التجريبي**: أسعار حقيقية من MEXC، لكن **أموال وهمية** — لا يلمس رصيدك الحقيقي.
ستصلك رسالة على تيليجرام: "🤖 بدأ البوت".

## الخطوة 7: المتابعة
| ماذا تريد | اكتب في السيرفر | أو في تيليجرام |
|---|---|---|
| أشوف ماذا يفعل الآن | `./bot.sh logs` (للخروج Ctrl+C) | `الحالة` |
| الرصيد | — | `الرصيد` |
| الصفقات المغلقة | `./bot.sh trades` | `الصفقات` |
| إيقاف فتح صفقات جديدة | — | `ايقاف` |
| إغلاق كل شيء | — | `اغلاق الكل` |
| إيقاف البوت بالكامل | `./bot.sh stop` | — |

يمكنك إغلاق نافذة السيرفر وإطفاء جهازك — **البوت يستمر بالعمل على السيرفر**.
إذا أعيد تشغيل السيرفر، البوت يرجع يعمل تلقائياً.

> عندما تدخل السيرفر مرة أخرى لاحقاً، اكتب أولاً: `cd crypto/mexc_bot`

## الخطوة 8: التحويل للتداول الحقيقي (بعد أسبوعين على الأقل)
فقط إذا كانت نتائج التجربة مقبولة لك:
```bash
cd crypto/mexc_bot
./bot.sh live
```
اكتب `نعم` للتأكيد. وللرجوع للتجربة: `./bot.sh paper`.

أول صفقة حقيقية: راقبها في تطبيق MEXC وتأكد أنك ترى **وقف الخسارة (SL)** و**الهدف (TP)** مسجلين على الصفقة.
